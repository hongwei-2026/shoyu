怎么用

        
    
          
  • 可注册 / 登录保存长期数据，也可用游客模式先试用（数据随浏览器会话）。
    • 
          
  • 拍一下：上方大屏预览；下方左为选项、右为译文与日志。可分段转字，或勾选连续自动出字。
    • 
          
  • 传视频：左侧整段识别（可自选 ONNX / OCR / 混合），右侧边播仅本地预览；漏句在「补录」区保存。
    • 
          
  • 
            说话：写好可先「播放声音」或「展示给对方」；可存常用语或手语词本。
          
    • 
          
  • 
            识别模型：本应用部署的是 Uni-Sign → ONNX（普通摄像头）。英文连续句选 OpenASL，中文选 CSL-Daily。点顶部「模型」查看说明；OpenESL 为事件相机研究项目，当前未接入。
